# College Majors 演示问题

推荐上传并同时选择：`recent-grads.csv`、`all-ages.csv`、`grad-students.csv`、`majors-list.csv`。`women-stem.csv` 是 `recent-grads.csv` 的子集，只有做 STEM 女性比例专题时再选择，避免重复计数。

## 推荐问题

请联合分析美国大学专业与就业收入数据：

1. 核对各文件中的专业代码、专业名和类别能否正确对应，列出缺失或冲突记录。
2. 对近期毕业生，按专业类别汇总收入中位数、失业率和低薪工作占比；每项给出表现最好和最差的类别，并报告专业数与样本规模。
3. 比较相同专业在 `recent-grads.csv` 与 `all-ages.csv` 中的收入中位数。哪些专业的差距最大？说明这只是不同年龄口径的横截面对比，不能直接当成个人薪资增长。
4. 结合 `grad-students.csv`，找出研究生收入溢价较高、同时研究生失业率没有明显恶化的专业或类别。
5. 分析女性占比与近期毕业生收入中位数的相关关系；控制专业类别后，方向是否仍一致？不要把相关性表述为因果。

请生成一张类别对比表、两张清晰图表，并给出 5 条面向选专业者的通俗结论。所有结论必须标明使用的是哪一种人群口径，并注明数据来自 2010-2012 年美国调查。将图表保存为文件。

## 快速问题

近期毕业生中，哪些专业呈现“收入较高且失业率较低”？给出一个透明的筛选标准、前 10 名表格和一张散点图。
