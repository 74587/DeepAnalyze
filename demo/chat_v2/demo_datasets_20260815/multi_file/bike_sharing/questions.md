# UCI Bike Sharing 演示问题 / Demo Questions

上传并选择 `day.csv`、`hour.csv` 和 `Readme.txt`。 / Upload and select `day.csv`, `hour.csv`, and `Readme.txt`.

## 1. 日表与小时表核对 / Daily-hourly reconciliation

中文：这两份数据记录的每日骑行量一致吗？如果有差异，主要出现在哪些日期和用户类型？

English: Do the two files report the same daily ride totals? If not, on which dates and for which user types do the main differences appear?

## 2. 年度增长 / Annual growth

中文：2012 年的共享单车使用量比 2011 年增长了多少？注册用户和临时用户的增长情况有什么不同？

English: How much did bike-sharing usage grow in 2012 compared with 2011, and how did the growth differ between registered and casual users?

## 3. 工作日与非工作日高峰 / Working and non-working day peaks

中文：工作日和非工作日的骑行高峰分别在几点？一天中的使用模式有什么不同？

English: At what times does bike-sharing usage peak on working and non-working days, and how do their daily usage patterns differ?

## 4. 天气与骑行量 / Weather and ride demand

中文：不同天气状况下的共享单车使用量有什么差别？哪些天气下骑行量最高或最低，这些结果的数据量是否充足？

English: How does bike-sharing usage vary with the weather? Which conditions have the highest and lowest ride volumes, and is there enough data for each comparison?
